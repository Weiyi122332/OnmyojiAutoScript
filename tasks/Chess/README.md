- 平安京、七角山、海国、冥火四套阵容，默认七角山。旧配置中的流火、冥府、大江山、狐妖、荒川及其拼音值自动转为七角山。

- `hyakki_draft_enabled` 现在表示“百鬼优先所需御魂”：开启时优先阵容需求，关闭时仍参加投掷并随机选择已识别目标。
- 支持黄金复制术和特殊回合标志，并保留符咒复核、保段位、局数/时长限制及满币结束逻辑。
- 棋局独立补齐浮窗红叉、退出确认、奖励、庭院、协作和网络异常识别。处理弹窗后重新截图，连接失败时执行有界重连并恢复任务入口。

## 当前框架适配

- `module/atom/frame.py` 与 `BaseTask.runframe()` 提供相对区域读取；Frame 额外参数纳入当前图像缓存键。
- 图像服务支持多个定位标志、灰度及掩码匹配，继续使用当前项目的截图缓存和 RPC 失效回退。
- `BaseTask.ui_click_until_disappear()` 增加有界、多帧确认参数，供购买复核使用。
- 新版的 `max_clicks` 参数仅在棋局入口类中兼容，公共 `BaseTask` 本次没有修改。
- 满币后的周目标调度调用当前项目的 `set_next_run_next_monday()`，继续遵循本项目的 cron 调度约定。
- 全局导航识别六道必选页和棋局结算标志；普通奖励页仍由公共奖励页面推进，避免误归到棋局。
- `runtime/shared_ui.py` 只在棋局及本次棋局重连服务中使用 14 项公共模板副本；优先使用来源模板，再尝试当前模板。识别、点击和批量缓存使用同一套规则，保留已匹配坐标。
- 浮窗红叉使用棋局自己的规则，避免与 `GeneralBuffAssets.I_CLOSE_RED` 冲突；公共 `GameUi`、奖励页、邀请处理和调度器代码保持现有实现。
- 网络异常遵守当前实例的 `wait_10s`/`restart` 策略，也能读取来源的 `wait_5s` 值；连接失败最多尝试一次 30 秒重连，失败或再次断线交给既有异常重启机制。重连后重新执行启动恢复并清理旧回合、投掷及页面命中状态。
- `runtime/activity_watchdog.py` 只在棋局运行期间启用；连续 300 秒没有截图、识别或输入活动时触发现有 `GameStuckError` 恢复流程，退出棋局时恢复原线程的 profile 回调。
