# 每周购买

有周限额的商品使用购买开关。开启后点击向上双箭头，购买当前可选的最大数量；每次购买后重新读取剩余额度，继续购买直到售罄。御魂种类、部位和海汐御魂选择方式沿用原配置。

旧配置中的正数数量自动转为开启，0转为关闭；原来设置的数量不再作为这些限额商品的购买上限。

友情点和勋章商店的红蛋、破碎符咒保留数量输入，按输入数量购买。选择数量时优先点最大数量，再校正至本批目标数量。

余额不足、库存识别失败、购买失败或库存没有减少时结束当前商品的购买，避免无效重复点击。购买商品的开关和商店总开关均需开启。

每次识别商品和库存时，最多连续截图识别3秒，识别成功立即继续，超时才跳过；不固定等待3秒。库存区域跟随重新识别的商品位置，未识别到文字时不会当成售罄。
