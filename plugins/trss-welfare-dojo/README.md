# 福利寮检测插件

监听指定QQ群中指定成员的普通文字消息，按北京时间核对今天是否开启福利寮。不要求消息带命令前缀或 @机器人，不发送QQ消息。首次确认开启后当天保持开启状态，次日自动失效；状态保存在插件数据目录，重启可恢复。

## 安装

将安装包解压到 **机器人服务根目录**的 `plugins/trss-welfare-dojo`。确认结构如下，避免多套一层文件夹：

```text
plugins/trss-welfare-dojo/
├── index.js
├── package.json
└── src/
    ├── config.mjs
    ├── monitor.mjs
    └── service.mjs
```

无需安装额外依赖。重启机器人服务，日志出现“福利寮检测已启动”说明加载完成。

使用插件基类、Bot 群消息事件及群历史接口。NapCat 可继续作为 OneBot 协议端使用。

## 配置

首次加载会在 **机器人服务根目录**的 `data/oas-welfare-dojo/config.json` 生成配置和随机访问令牌，填写：

文件顶部的 `_comments` 是各字段的中文注释，修改下面对应字段的值即可。文件保持标准 JSON，不使用 `//` 或 `/* */` 注释。已有配置会在插件启动时自动补齐说明，保留已填写的配置值；除监听地址和端口外，修改配置后在下一次消息或接口查询时生效。

| 字段 | 含义 |
| --- | --- |
| enabled | 是否启用消息检测，默认 true |
| bot_id | 监听的机器人QQ号；单账号可留空，多账号建议填写 |
| group_id | 指定QQ群号，使用字符串 |
| member_id | 指定成员QQ号，使用字符串 |
| keywords | 开启关键词，多个词用换行或英文竖线分隔 |
| excluded_keywords | 排除/取消关键词，同样支持多个词 |
| api_token | 插件独立访问令牌，复制到 OAS |
| http_host | 接口监听地址，默认 0.0.0.0 |
| http_port | 接口端口，默认 2537；与协议接入端口分开 |
| history_page_size | 每页补读数量，默认100 |
| history_max_pages | 最多补读页数，默认5 |

除监听地址和端口外，保存配置后在下一次消息或接口查询时生效。修改监听地址或端口后需要重启机器人服务。配置错误期间接口返回503，修正后自动恢复。

指定机器人需要在群内。启动或新一天首次查询时通过 `getChatHistory` 补读当天消息，此后直接监听。协议必须支持群历史；接口失败时返回503，下次查询重试。超出补读页数范围的历史消息可能无法恢复。

首次确认前，排除词及较新的取消消息阻止开启。首次确认后不再查询历史，当天保持开启状态。

## OAS 对接

远程服务器需要开放插件端口；使用容器时还需映射该端口。OAS 道馆页面开启插件状态触发，填写：

- 接口地址：`http://服务器地址:2537/welfare-dojo/today`
- 插件访问令牌：上述配置的 `api_token`

OAS 默认北京时间20:00–22:00、每60秒查询，可自行修改。当天首次匹配后停止查询，当前任务结束后优先运行道馆，仍遵守星期、每日次数及休息设置。

## 接口

`GET /welfare-dojo/today`

请求头：`Authorization: Bearer <api_token>`。成功只返回当天日期和是否开启，不返回群号、成员、聊天或配置：

```json
{"date":"2026-10-09","opened":true}
```

未开启返回 `opened: false`。未授权返回401，补读或配置失败返回503，响应禁止缓存。日期固定按北京时间计算，OAS 会再次核对日期和布尔类型。

开发测试：`npm test`。
